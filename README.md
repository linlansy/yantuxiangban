# 研途相伴 2.8.6（安卓自用版）

用 Android Studio 打开本目录并等待 Gradle 同步，再选择真机或模拟器运行 `app`。

功能包括自由学习计时、积分流水、每日任务、三类兑换码、成就、主题商城、每周主动休息、补签卡、宠物成长、单日8小时来信、独立星空收藏、暂停彩蛋、状态鼓励语、周/月统计、学习日历、加密备份和 PIN 保护的管理页。星空夜读主题可在商城兑换，大耳狗主题由累计100小时成就的隐藏奖励解锁。所有数据只保存在本机。

2.8.0 将宠物满级成长线延长到累计学习 500 小时：10 小时孵化，之后按 15/22/30/40/52/66/82/100/120/142/166/194/226/262/302/346/394/446/500 小时逐级成长。等级下降不会收回已经获得的动作、表情、服装、配饰或摆件。宠物支持点击互动、学习中自动看书、暂停彩蛋、每日首次挥手和升级/完成学习庆祝；主服装、眼镜、围巾、头饰使用独立槽位，并可选择是否显示在专注页。

2.8.1 将宠物动作整体调慢，学习中的看书动画每轮约 7.2 秒并额外静止 1.4 秒，减少反复运动对专注的干扰。房间中的书堆、台灯、时钟、盆栽、星空球和目标板改为可缩放矢量摆件；圆框眼镜、目标围巾和星星头饰也增加了细节与层次。

2.8.2 将专注页的学习分类改为下拉选择，可在菜单中直接新增并选中分类。统计概览增加“本日”维度，并为分类分布增加彩色饼状图与百分比图例。

2.8.3 重新整理宠物模块：动作入口移到房间正下方，点击即可在房间中播放；装扮页按服装、配饰、表情和摆件分类。睡衣、图书馆马甲和星空礼服在没有专属逐帧素材的动作中也会保留服装并使用通用动态。删除容易错位的圆框眼镜和目标围巾，已解锁奖励自动替换为云朵坐垫和目标奖杯。

2.8.4 新增宠物拍照喂食系统：支持相机与相册、通义千问食物识别、约40种食物确认、危险食物温柔拒绝、每天3次喂食、亲密度、食物日记及五种外观通用的24帧咀嚼动画。没有配置API时仍可手动选择食物。

2.8.6 完整重制宠物服装动作：星星睡衣、图书馆马甲和星空礼服均拥有与原版一致的点击、挥手、看书、伸懒腰、庆祝、喝水和趴下逐帧动作，只更换服装、不再使用整只角色旋转缩放的替代动画。食物识别目录扩充到 100 种以上，并统一为仅巧克力会被宠物温柔拒绝。

首次启动会要求设置 6 位管理 PIN，并显示一次恢复码。更新 APK 时请直接覆盖安装，不要先卸载；正式签名文件必须长期保留。

## 安装与更新

- 手机首次安装：复制 `dist/研途相伴-2.8.6-正式版.apk` 到手机，允许“安装未知应用”后打开安装。
- 后续更新：保持包名 `com.example.kaoyanfocus` 和 `signing/yantu-release.jks` 不变，仅提高 `versionCode`/`versionName` 后重新构建，再直接覆盖安装。
- 若手机仍安装早期调试签名的同包名版本，请先用 `dist/研途相伴-2.8.6-旧版覆盖安装包.apk` 原地升级并导出加密备份；该包用于保留旧数据，不能作为今后的正式签名。
- **不要先卸载旧版**，卸载会清除手机上的本地积分和记录。重大更新前可在“设置 → 数据管理”导出加密备份。
- 从旧调试签名切换为正式签名时不能直接覆盖：先在调试版导出加密备份，再卸载调试版、安装正式版并导入备份。此操作只需做一次。

## 构建

本机稳定构建环境为 JDK 21、Android SDK 35。工程路径含中文时，Gradle 的 Windows 单元测试进程可能无法识别路径，可先执行：

```powershell
subst R: "C:\Users\jason\Desktop\smm的学习软件"
cd R:\
$env:JAVA_HOME = "C:\Users\jason\.jdks\jbr-21.0.11"
.\gradlew.bat testDebugUnitTest assembleRelease
```

正式签名密钥与密码配置保存在 `signing/`。这两个文件已加入 `.gitignore`，请另外离线备份；丢失密钥后将无法覆盖更新已安装的正式版。

## 通义千问食物识别

可在“设置 → 管理设置 → AI识别”中输入API Key，配置会通过Android Keystore加密保存在本机。也可在已被忽略的 `local.properties` 中加入：

```properties
QWEN_API_KEY=sk-your-key
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen3-vl-flash
```

项目默认密钥会进入APK，仅适合个人自用；请在百炼控制台设置调用和消费上限。食物照片不会写入加密备份，换机恢复后保留名称、时间和亲密度记录，但显示缺图占位。
